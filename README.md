## The entry

```text
😊
```

One emoji. One smile. That is the whole program.

## Why this emoji

😊 — the smiling face with smiling eyes — is the single most
universally readable symbol of warmth in the Unicode set. It does
not need a caption, a culture, or a context: closed happy eyes and
a soft smile read as genuine delight everywhere, on every device,
in every language. It is the emoji people actually send when they
mean "that made me happy", not the loud laugh (😂) or the
heart-eyes crush (😍) — it is quiet, sincere, and impossible to
misread. One glance, one smile. That is exactly what the brief asks
for.

## How to run

```bash
python3 main.py
```

Prints exactly `😊` followed by a newline, then exits with code 0.
Standard library only — no third-party imports, no arguments, no
input, fully deterministic. The file is UTF-8 encoded so the emoji
renders correctly on any system.
